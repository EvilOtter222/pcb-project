# RP2040 Console
A handheld game console built around a bare RP2040, on a PCB I designed from scratch in KiCad.

insert 

This is my first PCB. I have built things on breadboards before, but I had never used PCB software, so I picked a project that would force me to learn it properly: no dev board, just the RP2040 chip and everything it needs to run.

Features
-
Controller: RP2040 with 128 Mbit of flash and a 12 MHz crystal
Screen: 2.0 inch 240×320 IPS display (ER-TFT020-3) on a 14-pin ribbon connector
Controls: 8 game buttons (a D-pad and 4 action buttons) and an analog thumbstick
Sound: PAM8302 amplifier driving a small speaker
Power: USB-C, regulated down to 3.3 V. The same port is used for programming.
Board: 110 × 60 mm, 2 layers, with a ground fill on both sides
